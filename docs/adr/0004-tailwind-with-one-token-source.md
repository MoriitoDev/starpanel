# Tailwind for the web app, driven by one token source

The web app styled itself with one scoped `<style>` block in `App.svelte` plus 29 runtime CSS variables injected from the Dashboard's Theme. Adopt Tailwind v4 (`@tailwindcss/vite`) and declare every design value — colors, borders, radii, spacing, type — once in a single tokens stylesheet; utilities and components reference those tokens, never literal hex or pixel values. Theming stays dynamic because the token layer is declared as `var()`-backed (`@theme inline`), so the palette injected per mode keeps driving the same utilities. Rejected: hand-written scoped CSS (adequate for two components, does not scale to the settings and layout UI the redraw implies) and moving tokens to build-time constants (would forfeit runtime palette injection, which the Theme relies on today). Plugin widgets keep the CSS-variable contract of ADR-0003, since Tailwind's scanner runs at build time and cannot see a plugin folder dropped in later.
